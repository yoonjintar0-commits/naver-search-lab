# 네이버 쿼리 추정기

브라우저에서 그룹명과 콤마로 구분한 키워드, 추출 기간을 입력하면 네이버 검색광고 월간 검색수와 Data Lab 일별 지수로 검색량을 추정합니다. 회사 PC에서도 로그인 없이 사용할 수 있습니다.

- 필터 버튼으로 그룹·키워드 선택 화면을 펼칩니다. 그룹·키워드별 일별 추정 쿼리와 그룹 내 키워드의 전일 대비 증감을 비교합니다.
- PC·모바일은 월간 절대 검색량을 높이가 다른 누적 막대로 표시합니다.
- 성별·연령별 관심 흐름은 한 그룹 또는 한 키워드만 선택합니다. 연령 그래프는 모두(기본)/남성/여성 토글을 제공합니다. 독립적으로 정규화된 상대지수이며 성·연령별 절대 검색 건수나 구성비는 제공하지 않습니다.
- 새 검색은 이전 데이터 다운로드를 안내하고, 추출에 성공하면 이전 결과를 교체합니다. 자동 수집은 없습니다.
- 전체 Excel은 보이는 시트에 그룹/키워드/성별/연령/PC/MO/추정 쿼리수(정수)의 7개 열만 담습니다. 일별 날짜와 원본 지수는 숨김 복원 시트에 보관하며 업로드 시 원래 그래프를 복원합니다. 성·연령별 건수는 근거가 없어 공란입니다.
- 트렌드 API 예상 사용량은 `23 × ceil(중복 제외 키워드 수 / 5)`입니다. 검색광고 API 호출은 별도입니다. Budget은 이 사이트가 파악한 호출 시도 기준 추정치입니다.

## 구성

`docs/`는 GitHub Pages용 프런트엔드이며 `docs/config.js`에 공개 서버 주소가 들어 있습니다. `web/`는 동일한 원본 UI, `worker/runtime.js`는 서버 구현입니다. `node scripts/build-public.mjs`로 Pages 파일을 갱신합니다.

네이버 인증키는 서버 환경변수에만 보관합니다. 브라우저 또는 저장소에는 인증키를 넣지 않습니다. 서버는 Cloudflare Worker 호환 환경과 `BUCKET` R2 바인딩을 사용하며, 다음 환경변수를 요구합니다: `NAVER_HUB_CLIENT_ID`, `NAVER_HUB_CLIENT_SECRET`, `NAVER_SEARCHAD_LICENSE`, `NAVER_SEARCHAD_SECRET`, `NAVER_SEARCHAD_CUSTOMER`.

## 추정 방식

일별 추정량 = 월간 PC 검색수 × 해당일 PC 지수 / 기준 30일 PC 지수 합 + 월간 MO 검색수 × 해당일 MO 지수 / 기준 30일 MO 지수 합.

기준 기간은 수집일 전날까지 30일로 가정합니다. PC/MO의 조회 기간과 기준 기간을 같은 요청에 포함하여 지수 스케일을 일치시킵니다. 실제 일별 검색 건수가 아닌 고정 보정계수를 적용한 소급 추정입니다. `<10`, 기준 지수 누락 및 0 합계는 추정하지 않습니다.
