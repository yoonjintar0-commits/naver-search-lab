# 브랜드 종합 분석

한 줄에 하나씩 입력한 키워드를 하나의 분석 대상으로 묶고, 가장 큰 **일별 흐름** 그래프에서 전체 키워드의 일별 추정 쿼리, 월간 광고비, 유튜브 발생 조회수와 뉴스 이슈를 비교합니다.

- 브랜드명 옆 **자동** 버튼은 NAVER 검색광고 API의 연관 키워드를 최대 30개 입력합니다. 브랜드명을 먼저 두고 브랜드 포함 키워드와 검색량을 기준으로 정렬·중복 제거합니다. 추천 목록은 줄 단위로 수정할 수 있고 추천 전으로 되돌릴 수 있습니다. 추천만으로 기존 분석을 교체하거나 트렌드 API Budget을 차감하지 않습니다.
- 쿼리는 모든 키워드 합계 한 줄입니다. 실제 관측점을 지나는 monotone cubic 곡선으로 그리며 결측 구간을 연결하지 않습니다. 세부 키워드 그래프도 일별 추정 건수만 사용합니다.
- 광고비는 `경쟁사월별집계세로` XML `.xls` 또는 `.xlsx` 파일을 업로드합니다. 지상파·케이블·종편은 TV, 디지털 동영상·배너는 디지털, 옥외 매체는 옥외, 라디오는 라디오, 신문·잡지는 인쇄로 합칩니다. 금액 단위는 천원이며 원본 `계`와 대조합니다. 원본에 없는 매체는 결측으로 유지합니다. 광고주가 여러 개면 선택할 수 있습니다.
- 월간 광고비는 월간 누적 막대입니다. 일별로 균등 배분하거나 존재하지 않는 일별 금액을 만들지 않습니다. 화면의 부분월에도 원본 월간 값을 표시합니다.
- 채널 URL은 분석 정보로 저장합니다. 타인 채널의 과거 기간별 발생 조회수는 공개 누적 조회수에서 복원할 수 없습니다. YouTube Studio의 날짜/조회수 또는 Date/Views CSV를 올려 실제 일별 또는 월별 발생 조회수를 표시합니다. 채널 소유자의 OAuth 승인이 필요한 Analytics API는 이 버전에서 연결하지 않습니다.
- 검색 완료 후 선택 기간을 월별로 나눠 관련 뉴스를 수집합니다. Google News RSS를 우선 사용하고 실패 시 NAVER 뉴스 검색으로 보완합니다. 발행일은 한국시간 기준이며, 기간 밖·관련 없는 기사와 동일 제목 중복을 제외합니다. 뉴스가 많은 날과 검색 흐름의 변화를 참고해 최대 16일을 번호로 표시합니다. 제목/번호에 마우스를 올리거나 누르면 제공 요약과 원문을 확인할 수 있습니다. 아카이브 전체 수집이나 인과관계를 보장하지 않으며 실패한 달을 별도로 표시합니다. NAVER 보완에는 검색 API 사용 권한이 필요합니다.
- 세 지표는 각각 별도의 축을 사용합니다. YouTube 월간 자료는 월간 관측점으로 표시하고 일별 값으로 보간하여 저장하지 않습니다. 곡선은 시각적 연결입니다.
- 새 추출 전에 기존 분석의 Excel 저장을 안내하고, 성공한 결과로 이전 분석을 교체합니다. 자동 예약 수집은 없습니다.
- Excel은 보이는 시트에 그룹/키워드/성별/연령/PC/MO/추정 쿼리수(정수) 7개 열만 담습니다. 날짜·원본 지수·광고비·조회수·이슈는 숨김 복원 시트에 담고 업로드 시 복원합니다. 성·연령별 건수는 근거가 없어 공란이며 상대지수 그래프는 표시하지 않습니다.

## 구성

`docs/`는 GitHub Pages 프런트엔드이며 `docs/config.js`에 공개 서버 주소가 있습니다. `web/`는 원본 UI입니다. `worker/analysis.js`는 외부 지표 검증과 뉴스 수집, `worker/runtime.js`는 네이버 쿼리 수집과 저장소 API입니다. `node scripts/build-public.mjs`로 Pages 파일을 갱신합니다.

인증키는 서버 환경변수에만 보관합니다. Cloudflare Worker 호환 서버와 `BUCKET` R2 바인딩, 다음 환경변수가 필요합니다: `NAVER_HUB_CLIENT_ID`, `NAVER_HUB_CLIENT_SECRET`, `NAVER_SEARCHAD_LICENSE`, `NAVER_SEARCHAD_SECRET`, `NAVER_SEARCHAD_CUSTOMER`.

트렌드 API 예상 사용량은 `23 × ceil(중복 제외 키워드 수 / 5)`입니다. 광고비·조회수 파일 업로드는 트렌드 API를 사용하지 않습니다. 뉴스와 검색광고 호출은 별도입니다. Budget은 이 사이트가 파악한 호출 시도 기준 추정치입니다.

## 쿼리 추정 방식

일별 추정량 = 월간 PC 검색수 × 해당일 PC 지수 / 기준 30일 PC 지수 합 + 월간 MO 검색수 × 해당일 MO 지수 / 기준 30일 MO 지수 합.

기준 기간은 수집일 전날까지 30일로 가정합니다. PC/MO의 조회 기간과 기준 기간을 같은 요청에 포함하여 지수 스케일을 맞춥니다. 실제 일별 검색 건수가 아닌 고정 보정계수를 적용한 소급 추정입니다. `<10`, 기준 지수 누락 및 0 합계는 추정하지 않습니다.
